# Componentes de terceros

ARAEMKA PDF utiliza componentes de terceros que conservan sus respectivas
licencias, avisos y autoría. Las versiones concretas instaladas para cada build
constan en el registro de GitHub Actions de la release.

| Componente | Uso principal | Licencia declarada por el proyecto |
|---|---|---|
| PyMuPDF | Lectura, edición y escritura de PDF | GNU AGPL v3 o licencia comercial |
| pdf2docx | Conversión PDF a Word | MIT |
| Pillow | Procesamiento de imágenes | HPND |
| python-docx | Escritura de documentos Word | MIT |
| tkinterdnd2 | Arrastrar y soltar en la interfaz | MIT |
| NumPy | Cálculo usado por dependencias | BSD-3-Clause |
| OpenCV | Procesamiento usado por dependencias | Apache-2.0 |
| FontTools | Gestión tipográfica usada por dependencias | MIT |

Consulta los textos de licencia incluidos por cada dependencia y sus
repositorios oficiales. Este documento es informativo y no sustituye esos
textos.
